# Prag

A static PDF question-answering app. Extracts PDF text in the browser, creates 1,024-dimensional NVIDIA `nvidia/nv-embedqa-e5-v5` embeddings, and stores/retrieves passages from Pinecone. Answers are generated by NVIDIA `nvidia/nemotron-3-ultra-550b-a55b` and include source page numbers.

## Run it

Open `index.html` in a modern browser or deploy this repository as a **Static** Hugging Face Space. There is no build step or application server.

1. Open **Set up your workspace** and enter NVIDIA and Pinecone API keys.
2. Choose **Add a PDF**, select a text-based PDF, and enter a Pinecone index name. The app creates the index when it does not exist (AWS `us-east-1`, cosine metric, 1,024 dimensions), then chunks, embeds, and upserts the document. The index name is used as its Pinecone namespace.
3. To use an existing index, select **Open a library**, enter its name, and connect. The app reads the index host from Pinecone and checks that the dimension is 1,024.
4. Ask a question in the composer. The app retrieves the six closest passages and asks NVIDIA to answer from those passages.

API keys are kept only in JavaScript memory in the open tab and are not saved to local storage. They are cleared when the page reloads or closes. Use personal or limited-scope keys; this is a browser-only app and users with access to the page can inspect their own session's network requests. Static hosting cannot keep a shared provider credential secret.

## Browser access

The page calls NVIDIA and Pinecone REST APIs directly. Provider CORS policies, browser extensions, network policy, rate limits, and account permissions can affect requests from a Hugging Face Space. If the browser reports a CORS error, a static page cannot proxy that request; a small trusted backend would be needed. Scanned PDFs need OCR before their text can be indexed; this app currently reports when it finds no extractable text.
